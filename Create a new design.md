It’s time to create your first design in Studio! Below is the Welcome Screen you'll see by default whenever Studio is launched. 
![image](https://studiohelp.bricklink.com/hc/article_attachments/24162295253015)

To start a new project, you can: 
From the Welcome Screen, click Create New (A). Studio will create a new tab.
Click File | New.
Use the keyboard shortcut Ctrl + N. 
You can then add parts to your design.

Need help getting started? Here’s a few different ways to start building in Studio.

1. Try building against a Reference Image. You can build a perfect scale model of your furry friend, which in this case is... an elephant?

![image](https://studiohelp.bricklink.com/hc/article_attachments/19046385091351)

2. Import an official LEGO® set to build or modify. Time to add some laser cannons to your classic castles!

![image](https://studiohelp.bricklink.com/hc/article_attachments/19046370651543)

3. Import a MOC from the Studio Gallery and put your own spin on it. Only downloadable designs can be imported.

![image](https://studiohelp.bricklink.com/hc/article_attachments/23460656946327)

4.Try out the Mosaic feature by uploading your own image. Maybe you’re looking to create a 2D build of a cute pet photo, or you want to gift your best friend a portrait of their own face. Whatever it is, Mosaic can make it! Check out the similar Sculpture feature to turn 3D models into brick sculptures.

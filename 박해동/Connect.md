# 🔗 브릭링크 연동 (Connect to BrickLink)

Studio 2.0은 BrickLink 서비스와 직접 연동되어, 설계한 모델에 필요한 부품을 확인하고 구매 목록에 추가하는 기능을 제공합니다.

### 1. BrickLink 계정 로그인
연동 기능을 사용하려면 먼저 브릭링크 계정으로 로그인해야 합니다.

1.  Studio 상단 툴바의 오른쪽 상단에 있는 **[Connect]** 버튼을 클릭합니다.
2.  팝업 창에서 BrickLink 사용자 이름(또는 이메일)과 비밀번호를 입력합니다.
3.  로그인이 완료되면 버튼이 사용자 이름으로 바뀌며 연동 상태가 유지됩니다.

    ![Connect](https://studiohelp.bricklink.com/hc/article_attachments/20960978033687)
    
### 2. 보유 부품 목록 연동 (My Inventory)

Studio 내에서 사용자가 이미 보유하고 있는 브릭 목록을 확인할 수 있습니다.

* **기능:** BrickLink의 'My Inventory'에 등록된 부품 데이터를 Studio의 부품 팔레트와 연동합니다.
* **장점:** 실제 보유한 부품만 사용하여 모델을 설계할 수 있어, 제작 가능 여부를 즉시 판단할 수 있습니다.
* **설정:** 부품 팔레트 설정에서 'My Inventory'를 선택하여 필터링할 수 있습니다.

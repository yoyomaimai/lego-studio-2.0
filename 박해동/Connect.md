# 🔗 Connect (연결)

**Connect 툴**은 빌더가 정밀하거나 까다로운 연결을 수행할 수 있도록 돕는 도구입니다. 
연결 지점을 직접 선택하여 부품을 이동하고 결합할 수 있으며, 특히 연결 가능한 지점이 많아 원하는 대로 조립하기 어려울 때 매우 유용합니다.

### 1. Connect 툴 실행하기
*   툴바에서 **Connect 아이콘**을 클릭하여 활성화합니다.
*   툴이 활성화되면 아이콘이 파란색으로 변하며, 마우스 포인터 옆에 Connect 아이콘이 나타납니다.

    ![Connect](https://studiohelp.bricklink.com/hc/article_attachments/20960978033687)
    
### 2. Connect 툴 사용 방법

도구를 선택하기 전에 선택된 부품이 없는 경우, 다음 순서대로 진행합니다.

1.  모델에서 부품을 하나 선택한 후, 마우스 포인터를 해당 부품 위로 가져갑니다.
![1번 설명 이미지](https://studiohelp.bricklink.com/hc/article_attachments/20960950115479)
2.  해당 부품의 모든 연결점(Connector)이 **작은 파란색 정육면체 또는 실린더** 모양으로 표시됩니다.
3.  원하는 연결점 하나를 클릭하여 선택합니다.
4.  마우스 포인터를 움직입니다. 선택한 연결점에서 마우스 포인터까지 선이 이어집니다.
5.  다른 부품 위로 마우스를 가져갑니다..
6.  해당 부품의 호환 가능한 연결 지점들이 작은 파란색 정육면체 또는 작은 파란색 실린더로 표시됩니다. 선택된 부품의 호환 가능한 연결점들도 표시되지만 선택할 수는 없습니다.
7.  첫 번째 부품을 부착하려는 연결 지점을 클릭합니다.
![7번 설명 이미지](https://studiohelp.bricklink.com/hc/article_attachments/20960978060311)
8.  두 개의 선택된 연결점이 연결되도록 부품이 이동합니다.
